# Portfolio - Noa Pascal

Monorepo containing the personal portfolio application and its upcoming backend service.

## Repository Structure

```text
.
├── frontend/        # React + TypeScript + Vite frontend application
├── backend/         # Backend API service (in progress)
└── .github/         # GitHub Actions workflows and configuration
```

## Getting Started

### Frontend Development

Navigate to `frontend/`:

```bash
cd frontend
npm install
npm run dev
```

The site will be available locally at `http://localhost:3000`.
